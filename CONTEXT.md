# Domain context

## Curriculum

The ordered Kubernetes learning path shown under Docs. A Curriculum contains lightweight
lesson and mission catalog entries used for navigation, search, progress, and neighbors,
while each authored lesson or mission implementation contains the full teaching blocks,
labs, manifests, and checks kept behind the server interface. Only the current body is
rendered, and only narrow interactive data crosses the client seam.

## Brand

The public product identity shared by metadata, navigation, account communication,
community attribution, and landing-page copy. The Brand module owns its configuration and
mark so the displayed identity and browser favicon stay consistent. Stable runtime identifiers
such as storage keys and simulated image names are not part of the Brand.
